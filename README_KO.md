# 세무 한 걸음 · Streamlit 전산세무 2급 학습실

Python으로 실행하는 직업훈련생 20명용 학습 사이트입니다.

## 1. 설치와 실행

Python 3.10 이상을 설치한 후 압축을 풀고, app.py가 있는 폴더에서 실행합니다.

~~~powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
~~~

브라우저에서 http://localhost:8501 에 접속합니다. Windows에서는 실행.bat를 더블클릭해도 됩니다. 패키지가 없다면 위 설치 명령을 먼저 실행하세요.

검증 환경: Python 3.13.5 / Streamlit 1.45.1. requirements.txt는 Streamlit 1.45 이상 2 미만을 사용합니다.

## 2. 학생 사용

1. 사이드바의 학생 입장을 선택합니다.
2. 소속과 이름을 입력합니다. 다시 들어올 때도 똑같이 입력합니다.
3. 학습하기에서 입문·필기·실기 → 과목 → 단원 탭을 선택합니다.
4. 배우기 → 해 보기 → 확인하기 순서로 진행합니다.
5. 확인하기는 단원별 OX 3문항과 4지선다 5문항입니다. 제출 즉시 정답과 해설이 표시됩니다.
6. 틀린 문제는 오답 노트에 자동으로 모입니다. 이유를 메모하고 다시 풀 수 있습니다.

동일 소속·이름은 같은 학생으로 처리합니다. 동명이인은 이름 뒤에 번호를 붙이세요. 정원은 서로 다른 소속·이름 조합 20명입니다. 기존 학생은 정원이 차도 다시 입장할 수 있습니다.

이름을 입력하는 방식은 간편한 학습자 식별입니다. 다른 학생의 소속·이름을 아는 사람이 같은 기록으로 입장할 수 있으므로 수업 참여자에게만 주소를 공유하세요. 학생별 비밀번호·외부 계정 인증은 포함하지 않습니다.

## 3. 교수자 사용

사이드바의 교수자 대시보드를 열면 초기 비밀번호가 자동 생성됩니다. 실행 폴더의 data/teacher_password.txt를 열어 비밀번호를 확인하고 입력하세요. 이 파일과 교수자 비밀번호를 학생에게 배포하지 마세요.

교수자 비밀번호를 직접 지정하려면 .streamlit/secrets.example.toml을 .streamlit/secrets.toml로 복사한 뒤 teacher_password 값을 수정하고 서버를 다시 실행합니다. 클라우드에서는 해당 호스팅의 Secrets 설정에 다음 항목을 넣습니다.

~~~toml
teacher_password = "충분히-긴-나만의-교수자-비밀번호"
~~~

환경변수 TEACHER_PASSWORD도 지원합니다. 우선순위는 Streamlit Secrets → 환경변수 → 자동 생성 파일입니다. 비밀번호는 소스에 넣지 않습니다.

교수자는 학생별·과목별 진도, 최초/최근 정답률, 모든 응답, 오답 메모, 많이 틀린 문항, 선택지별 응답 수를 확인할 수 있습니다. 학생 현황과 응답 기록은 Excel에서 열 수 있는 UTF-8 BOM CSV로 다운로드합니다. 새 응답 확인은 최신 기록 새로고침을 누르세요.

## 4. 20명이 함께 쓰기

교수자와 학생이 **동일한 서버 주소**에 접속해야 기록이 한곳에 모입니다. 학생 각자 다른 컴퓨터에서 app.py를 실행하면 데이터가 분리됩니다.

동일한 교실 네트워크에서 다른 기기의 접속을 받으려면 서버 컴퓨터에서 다음처럼 실행합니다.

~~~powershell
python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
~~~

학생은 서버 컴퓨터의 내부 IP 주소와 포트 8501로 접속합니다. 접속 가능 여부는 기관 네트워크·방화벽 설정에 따릅니다. 외부 서비스에는 HTTPS와 수업 참여자 접근 제어를 설정하세요.

기록은 서버의 data/classroom.db에 저장됩니다. SQLite는 WAL 모드와 연결별 트랜잭션을 사용합니다. 하나의 앱 서버와 하나의 저장 경로를 사용하는 20명 수업을 대상으로 합니다.

TAX_DB_PATH 환경변수로 DB 경로를 바꿀 수 있습니다. 재시작 후에도 유지되는 영구 디스크를 지정하세요. Streamlit Community Cloud 등 임시 파일시스템에서는 재배포·휴면·재시작 시 SQLite 기록이 사라질 수 있으므로, 실제 수업에는 영구 디스크를 제공하는 호스팅을 사용해야 합니다. 여러 서버 인스턴스에서 서로 다른 SQLite 파일을 쓰는 구성은 지원하지 않습니다.

## 5. 구성과 기준

- 31개 단원, 핵심 개념 93개, 확인 문항 248개.
- 입문: 회계 용어·차대변·분개·재무제표.
- 필기: 재무회계 7단원, 원가회계 5단원, 세무회계 5단원.
- 실기: 재무·원가 3단원, 부가가치세 3단원, 원천제세 4단원.
- 단계 진도 = 완료한 단계 수 / 93. 단원 완료 = 세 단계 모두 완료.
- 확인하기는 8문항에 모두 응답하면 완료할 수 있습니다. 오답이어도 응답한 것으로 집계합니다.
- 정답률은 응답한 문항을 분모로 계산합니다. 최초와 최근 응답을 구분하고 전체 재도전 내역을 보관합니다.
- 오답 노트는 틀린 이력 전체를 보존합니다. 최근에 맞힌 문항은 복습 완료로 표시합니다.

**2027년 공식 출제기준은 2026년 11월 14일 검색에서 확인하지 못했습니다.** 한국세무사회 공개 평가범위를 바탕으로 한 잠정 학습안입니다. 공식 공고와 2027 적용 세법을 확인한 뒤 수정해야 합니다. OX는 학습용이고, 실기 화면은 KcLep의 실제 프로그램을 대체하지 않습니다. 세율·공제한도·보험료율을 포괄하는 완성형 2027 교재로 인증된 자료가 아닙니다.

참고 자료는 앱의 학습 안내·출처에 있습니다. 기초 회계는 일반기업회계기준의 학습 범위로 직접 요약했고, 세무 내용은 국세청 부가가치세·원천징수 안내를 참고했습니다. 학습 예제는 직접 작성했습니다.

## 6. 파일

| 파일 | 역할 |
|---|---|
| app.py | Streamlit 학생·교수자 화면 |
| database.py | SQLite 기록, 정원 제한, 비밀번호 확인 |
| learning.py | 학습 데이터 로딩, 문항 생성, 집계 |
| content.json | 과목·단원·핵심 개념·예제 원본 |
| requirements.txt | 설치할 Python 패키지 |
| .streamlit/config.toml | 밝은 파스텔 테마 |
| .streamlit/secrets.example.toml | 교수자 비밀번호 설정 예시 |
| test_model.py / test_ui.py | 데이터·화면 기능 검증 |
| backup_database.py | 실행 중에도 일관된 DB 백업 |

## 7. 백업과 검증

~~~powershell
python backup_database.py
python -m unittest test_model -v
python test_ui.py
~~~

백업은 backups/ 폴더에 생성됩니다. data/teacher_password.txt도 별도로 안전하게 보관하세요. 테스트는 임시 DB와 가상 학생을 사용하며 실제 학습 DB에 테스트 기록을 남기지 않습니다.

실제 주민등록번호 등 민감한 정보는 입력하지 않습니다. 배포할 소스 압축에는 data/, backups/, .streamlit/secrets.toml을 포함하지 마세요.
